# 🐟 Fischord

A high-craft, realistic dark-mode web chat client modeled closely after Discord's modern desktop UI (Ash/Onyx dark theme). Built entirely as a single, zero-dependency file (`index.html`).

![Fischord UI Preview](https://images.unsplash.com/photo-1618005182384-a83a8bd57fbe?w=1200&q=80)

## ✨ Features

- **Authentic Discord Proportions**: Dense, crisp desktop app layout featuring a 72px server rail, 240px channel sidebar, main chat, and 240px member list.
- **Email Authentication**: Secure email login mock that sets up your active user profile dynamically.
- **Dynamic Server & Channel Creation**: Create custom servers and text/voice channels on the fly.
- **Interactive Voice Channels**: Connect to voice channels with real-time status indication and a working disconnect option.
- **Local Persistence**: All servers, channels, and messages are automatically saved to your browser's `localStorage`.
- **Zero Build Tools**: Contained completely inside a single `index.html` file—no complex bundlers, node modules, or build configurations required.

## 🚀 Quick Start / Hosting on GitHub Pages

1. Upload your `index.html` file and your `README.md` to the main branch of your GitHub repository.
2. Go to your repository **Settings** tab.
3. Click on **Pages** in the left sidebar.
4. Under **Build and deployment**, select **Deploy from a branch** and set the branch to `main` (or `master`) and `/ (root)`.
5. Click **Save**! Your Fischord app will be live on GitHub Pages in seconds.
